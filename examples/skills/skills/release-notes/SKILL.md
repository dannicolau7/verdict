---
name: release-notes
description: Turn a list of merged changes or commit messages into user-facing release notes grouped as Added, Changed and Fixed.
---

Write release notes from the changes the user gives you.

- Group under `### Added`, `### Changed`, `### Fixed`; omit empty groups.
- One bullet per user-visible change, written for users, not developers.
- Drop internal-only changes (refactors, CI, dependency bumps without user impact).
